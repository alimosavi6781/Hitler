# 📸 اینستامـنیجر — پنل مدیریت هوشمند اینستاگرام

سیستم کامل مدیریت پیج اینستاگرام — دو حالت: **فروشگاهی** و **خبری**

## 🏪 حالت فروشگاهی
- 🖼️ **ساخت پست** — طراحی خودکار تصویر پست (۱۰۸۰×۱۰۸۰) با برندینگ فروشگاه شما + کپشن و هشتگ هوشمند فارسی
- 📱 **ساخت استوری** — قالب‌های استوری (محصول، نکته روز، جمله انگیزشی، سوال از مخاطب)
- ⏰ **انتشار زمان‌بندی‌شده** — تقویم انتشار، تأیید پیش‌نویس‌های هوشمند، و انتشار خودکار از طریق Instagram Graph API
- 📊 **آنالیز پیج** — روند فالوور، ریچ، بازدید پروفایل + ثبت دستی آمار یا دریافت خودکار اینسایت
- 🚀 **رشد پیج** — پیشنهادهای هوشمند رشد، چک‌لیست تسک‌ها و گزارش هفتگی

## 📰 حالت خبری
- 🌐 **۹ منبع خبری فارسی** (بی‌بی‌سی فارسی، ایرنا، ایسنا، مهر، یورونیوز فارسی، گوگل‌نیوز و...) + افزودن منبع RSS دلخواه
- 🔄 **دریافت خودکار اخبار** ایران و جهان — دو بار در روز (۸:۳۰ و ۱۴:۳۰) + دکمه دریافت دستی
- ⚡ **استوری فوری لحظه‌ای** — به محض رسیدن «خبر فوری»، بلافاصله استوری ساخته و ۱۰ دقیقه بعد منتشر می‌شود (بدون انتظار برای زمان‌بندی روزانه)
- 🗞️ **ساخت خودکار پست خبری** — هر روز ساعت ۹ صبح از مهم‌ترین خبر تازه، پست پیشنهادی می‌سازد (با تأیید تو منتشر می‌شود)
- 📱 **۲ استوری خبری خودکار** در روز
- 🎨 **۳ قالب تصویر خبری** با انتخاب هوشمند خودکار:
  - 📰 استاندارد — تیتر بزرگ + خلاصه
  - 📊 آماری — استخراج خودکار اعداد کلیدی خبر و نمایش به‌صورت کارت (قیمت دلار/طلا، آمار و...)
  - 💬 نقل‌قول — نمایش خودکار متن داخل گیومه «...»
  - 🔴 خبر فوری — پس‌زمینه قرمز ویژه برای خبرهای اضطراری
- دسته‌بندی هوشمند اخبار (سیاسی، اقتصادی، ورزشی، فناوری، فرهنگی، حوادث) با رنگ اختصاصی هر دسته
- ✍️ افزودن خبر دستی + ساخت پست/استوری از هر خبر با یک کلیک (انتخاب قالب یا حالت خودکار)

## اجرا

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000
```

یا به‌سادگی: `bash run.sh`

سپس مرورگر را روی `http://localhost:8000` باز کنید.

## حالت‌های انتشار

| حالت | توضیح |
|------|-------|
| **دستی (پیش‌فرض)** | سیستم همه پست‌ها/استوری‌ها را می‌سازد و در زمان مقرر «آماده انتشار» می‌کند؛ شما با یک کلیک بسته (تصویر + کپشن) را دانلود و منتشر می‌کنید. |
| **خودکار (با API متا)** | پس از اتصال Instagram Graph API، انتشار کاملاً خودکار انجام می‌شود و اینسایت پیج هر شب ذخیره می‌شود. |

راهنمای قدم‌به‌قدم اتصال API متا: در تب «تنظیمات ← اتصال اینستاگرام» داخل پنل + فایل [GUIDE_FA.md](GUIDE_FA.md)

## قابلیت‌های خودکار

- هر روز **ساعت ۰۸:۳۰ و ۱۴:۳۰** دریافت خودکار اخبار از منابع خبری + بررسی خبرهای فوری (استوری لحظه‌ای)
- هر روز **ساعت ۰۹:۰۰** تولید محتوای امروز:
  - پیج خبری: ۱ پست خبری پیشنهادی + ۲ استوری خبری
  - پیج فروشگاهی: ۱ پست محصول پیشنهادی + ۲ استوری
- هر شب **ساعت ۲۳:۴۵** اینسایت پیج ذخیره می‌شود (در صورت اتصال API)
- هر دقیقه پست‌های سررسیدشده بررسی و منتشر می‌شوند

همه زمان‌ها به وقت تهران (Asia/Tehran) هستند. نوع پیج (فروشگاهی/خبری) از تب تنظیمات قابل تغییر است.

## ساختار پروژه

```
app.py              → سرور FastAPI (همه APIها)
core/
  db.py             → دیتابیس SQLite
  content.py        → تولید کپشن و هشتگ فارسی
  images.py         → موتور طراحی تصویر (پست/استوری/خبری — Pillow، آفلاین)
  news.py           → موتور خبر (RSS، دسته‌بندی، کپشن خبری)
  ig_api.py         → کلاینت Instagram Graph API
  analytics.py      → اینسایت + پیشنهادهای رشد
  scheduler.py      → زمان‌بند خودکار
static/
  fonts/            → فونت وزیرمتن
  index.html, style.css, app.js → رابط کاربری فارسی RTL
assets/samples/     → عکس‌های نمونه محصول
data/, uploads/, generated/  → دیتابیس و فایل‌های تولیدی (در گیت نیستند)
```

## نکات مهم

- محدودیت API اینستاگرام: حداکثر ۲۵ انتشار در روز.
- برای انتشار خودکار، سرور باید آدرس عمومی (قابل دسترس از اینترنت) داشته باشد تا اینستاگرام بتواند تصویر را بخواند؛ در غیر این صورت از حالت دستی استفاده کنید.
- دریافت RSS روی سرور خودِ کاربر انجام می‌شود؛ اگر محیط اجرا دسترسی به منابع خبری نداشته باشد، خبرهای قبلی و افزودن خبر دستی همچنان کار می‌کنند.
- استوری‌های منتشرشده از طریق API امکان استیکر/لینک ندارند.
