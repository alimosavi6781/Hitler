# ربات فارسی هشدار ورود ارز دیجیتال

یک ربات تلگرام سبک و آماده اجرا برای پایش آنلاین بازار کریپتو؛ مخصوص تنظیم انتخاب‌شده:

- بازار: **ارز دیجیتال**
- سبک: **کوتاه‌مدت (۱۵ دقیقه با تأیید ۱ ساعت)**
- ریسک: **متوسط**
- نوع معامله: **اسپات و بدون اهرم**
- زبان رابط: **فارسی**

ربات فقط با کتابخانه‌های استاندارد پایتون نوشته شده است؛ بنابراین `pip install` لازم ندارد.

## قابلیت‌ها

- قیمت آنلاین BTC، ETH، SOL، BNB و نمادهای `USDT` انتخابی
- تحلیل EMA 9/21/50، RSI 14، MACD، ATR، حجم و شکست سقف ۲۰ کندل
- هشدار خودکار «بررسی برای ورود» فقط پس از چند تأیید هم‌زمان
- هشدار ضعف روند برای کسی که معامله خرید باز دارد
- هشدار یک‌باره رسیدن قیمت به عدد دلخواه
- محدوده ورود احتمالی، حد بی‌اعتباری/ضرر و دو هدف نمونه در هشدار صعودی
- محاسبه اندازه معامله با `/risk`
- جلوگیری از ارسال تکراری یک سیگنال
- ذخیره کاربران، نمادها و هشدارها در SQLite
- منوی دکمه‌ای فارسی و ثبت خودکار دستورات تلگرام
- منبع اصلی داده: API عمومی **OKX**؛ پشتیبان: **Coinbase**
- Health endpoint برای سرویس‌های میزبانی: `/healthz`
- بدون نیاز به API Key صرافی، رمز کیف پول یا دسترسی معامله

> **مهم:** این ربات معامله‌ای انجام نمی‌دهد و هیچ سیگنالی سود را تضمین نمی‌کند. خروجی آن تحلیل الگوریتمی/آموزشی و دعوت به بررسی است. در هر معامله بیشتر از ۰٫۵ تا ۱٪ سرمایه را ریسک نکن و برای استفاده از اهرم به این ربات تکیه نکن.

## ۲) اجرای خیلی ساده روی کامپیوتر

### لینوکس / macOS

به Python 3.10 یا جدیدتر نیاز داری:

```bash
cp .env.example .env
nano .env
```

در `.env` این خط را با **توکن جدید** کامل کن:

```dotenv
BOT_TOKEN=توکن_جدید_اینجا
```

بعد اجرا کن:

```bash
python3 bot.py
```

اگر پیام `ربات @Pp6781bot با موفقیت متصل شد` را دیدی، در تلگرام وارد `@Pp6781bot` شو و `/start` را بزن.

### ویندوز

1. Python را از python.org نصب کن و هنگام نصب گزینه **Add Python to PATH** را فعال کن.
2. در پوشه پروژه PowerShell یا CMD باز کن.
3. اجرا:

```bat
copy .env.example .env
notepad .env
py bot.py
```

برای توقف در هر سیستم، `Ctrl + C` بزن.

### اجرای تست‌های آفلاین

```bash
python3 -m unittest -v
```

تست‌ها هیچ درخواستی به تلگرام یا بازار نمی‌فرستند.

## ۳) استفاده در تلگرام

دستورات اصلی:

| دستور | کار |
|---|---|
| `/start` | عضویت و نمایش منو |
| `/prices` | قیمت آنلاین نمادهای تو |
| `/analysis` | تحلیل همین حالا |
| `/alert` | ساخت هشدار قیمت با دکمه‌ها |
| `/alerts` | مشاهده و حذف هشدارها |
| `/addsymbol SOLUSDT` | افزودن یک نماد |
| `/delsymbol SOLUSDT` | حذف یک نماد |
| `/symbols` | نمادهای زیر نظر |
| `/risk 1000 1 64000 63000` | محاسبه اندازه معامله |
| `/id` | نمایش شناسه چت |
| `/cancel` | لغو عملیات جاری |
| `/help` | راهنما |

ساخت سریع هشدار قیمت:

```text
/alert BTCUSDT 70000 above
/alert ETHUSDT 3000 below
```

- `above`: وقتی قیمت به هدف برسد یا بالاتر برود.
- `below`: وقتی قیمت به هدف برسد یا پایین‌تر برود.
- هر هشدار قیمت یک‌بار فعال می‌شود و بعد غیرفعال خواهد شد.

### خصوصی‌کردن ربات

در حالت پیش‌فرض همه می‌توانند `/start` بزنند. برای استفاده شخصی:

1. داخل ربات `/id` را بزن و شناسه را کپی کن.
2. ربات را متوقف کن.
3. در `.env` بنویس:

```dotenv
ALLOWED_CHAT_IDS=123456789
```

4. دوباره ربات را اجرا کن. برای چند چت، شناسه‌ها را با ویرگول جدا کن.

## ۴) هشدار ورود دقیقاً چگونه ساخته می‌شود؟

ربات هر ۶۰ ثانیه داده‌ها را تازه می‌کند، اما فقط **کندل بسته‌شده** را مبنا قرار می‌دهد تا سیگنال لحظه‌ایِ ناپایدار نفرستد.

برای هشدار صعودی، مواردی مثل این‌ها امتیاز می‌گیرند:

1. روند یک‌ساعته بالای EMA 50 و EMA 9 بالای EMA 21 باشد؛
2. روند ۱۵ دقیقه هم صعودی باشد؛
3. تقاطع صعودی، شکست سقف ۲۰ کندل یا بازگشت معتبر بعد از پولبک رخ دهد؛
4. RSI بیش‌ازحد داغ نباشد؛
5. MACD و حجم حرکت را تأیید کنند.

فقط وقتی امتیاز و تأییدها به حد لازم برسند، پیام خودکار «هشدار بررسی برای ورود خرید (اسپات)» ارسال می‌شود. برای جلوگیری از پیام‌های پشت‌سرهم، هر نوع سیگنال برای هر نماد دو ساعت Cooldown دارد. ممکن است ساعت‌ها هیچ پیامی نیاید؛ این بهتر از تولید سیگنال اجباری و کم‌کیفیت است.

حد ضرر نمونه با ATR و حداقل فاصله ۰٫۶٪ محاسبه می‌شود و اهداف با نسبت تقریبی ۱٫۵ و ۲٫۵ برابر ریسک نمایش داده می‌شوند. این اعداد باید با شرایط واقعی صرافی، کارمزد و سرمایه خودت بررسی شوند.

## ۵) آنلاین نگه‌داشتن ربات

تا وقتی `python3 bot.py` روی یک دستگاه روشن اجرا شود، ربات آنلاین است. برای هشدار ۲۴ساعته یکی از روش‌های زیر را استفاده کن.

### روش مطمئن: سرور لینوکسی همیشه‌روشن

روی Ubuntu/Debian:

```bash
sudo apt update
sudo apt install -y git python3
sudo useradd --system --create-home bot || true
sudo mkdir -p /opt/crypto-alert-bot
sudo chown -R bot:bot /opt/crypto-alert-bot
```

فایل‌های پروژه را در `/opt/crypto-alert-bot` قرار بده، `.env` را بساز و سپس:

```bash
sudo cp deploy/crypto-alert-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now crypto-alert-bot
sudo systemctl status crypto-alert-bot
```

دیدن گزارش زنده:

```bash
sudo journalctl -u crypto-alert-bot -f
```

این روش روی VPS، مینی‌کامپیوتر یا VM رایگانِ همیشه‌روشن قابل استفاده است. شرایط سرویس‌های رایگان ممکن است تغییر کند.

### Docker روی کامپیوتر یا سرور

بعد از ساخت `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

دیتابیس در volume به نام `bot_data` نگه‌داری می‌شود. توقف:

```bash
docker compose down
```

### Koyeb؛ شروع رایگان و ساده

1. پروژه را در GitHub قرار بده.
2. در Koyeb گزینه **Create Web Service → GitHub** را انتخاب کن.
3. Repository را انتخاب و Builder را روی **Dockerfile** بگذار.
4. Instance رایگان و Region نزدیک مثل Frankfurt را انتخاب کن.
5. متغیر محرمانه `BOT_TOKEN` را با توکن جدید اضافه کن.
6. `DATABASE_PATH=/tmp/bot.db`، `CHECK_INTERVAL=60` و Port برابر `8000` بگذار.
7. Health check را `/healthz` انتخاب و Deploy کن.

**محدودیت مهم پلن رایگان:** سرویس رایگان ممکن است پس از مدتی بدون ترافیک ورودی خاموش شود و فایل SQLite هم پس از Deploy مجدد پایدار نماند. بنابراین برای هشدار واقعی ۲۴/۷، پلن رایگان را تضمینی فرض نکن؛ از سرویس همیشه‌روشن یا پلن دارای volume استفاده کن.

### Render؛ مناسب آزمایش، نه تضمین ۲۴/۷ رایگان

فایل `render.yaml` آماده است:

1. در Render گزینه **New → Blueprint** را بزن.
2. Repository را وصل کن.
3. مقدار محرمانه `BOT_TOKEN` را وارد کن.
4. Deploy را بزن.

پلن رایگان Render در زمان بی‌کاری خاموش می‌شود و SQLite مسیر `/tmp` موقت است. برای تست خوب است، ولی ممکن است هشدارها در زمان Sleep ارسال نشوند. پلن همیشه‌روشن/دیسک پایدار یا یک VM برای استفاده جدی مناسب‌تر است.

## تنظیمات `.env`

| متغیر | پیش‌فرض | توضیح |
|---|---:|---|
| `BOT_TOKEN` | الزامی | توکن جدید BotFather |
| `DATABASE_PATH` | `data/bot.db` | مسیر SQLite |
| `DEFAULT_SYMBOLS` | `BTCUSDT,ETHUSDT` | نمادهای اولیه |
| `CHECK_INTERVAL` | `60` | فاصله پایش، حداقل ۳۰ ثانیه |
| `POLL_TIMEOUT` | `50` | زمان Long Poll تلگرام |
| `HTTP_TIMEOUT` | `15` | مهلت درخواست بازار |
| `ALLOWED_CHAT_IDS` | خالی | فهرست چت‌های مجاز |
| `PORT` | `0` | پورت Health؛ در نمونه ۸۰۰۰ |
| `LOG_LEVEL` | `INFO` | سطح گزارش |

حداکثر ۸ نماد برای هر چت و ۲۰ هشدار قیمت فعال در نظر گرفته شده تا مصرف API کنترل شود.

## رفع اشکال

### `BOT_TOKEN تنظیم نشده است`

فایل `.env` را کنار `bot.py` بساز و توکن جدید را در آن قرار بده.

### `Conflict: terminated by other getUpdates request`

دو نسخه از ربات هم‌زمان با یک توکن در حال اجرا هستند. یکی را متوقف کن.

### قیمت دریافت نمی‌شود

- اینترنت سرور و ساعت سیستم را بررسی کن.
- ممکن است OKX یا Coinbase در کشور/میزبان تو موقتاً محدود باشد؛ ربات خودکار منبع پشتیبان را امتحان می‌کند.
- چند دقیقه بعد دوباره `/prices` را بزن و Log را ببین.

### هشدار تحلیلی نمی‌آید

هشدار فقط با بسته‌شدن کندل و تکمیل چند شرط ارسال می‌شود. با `/analysis` وضعیت فعلی را ببین و مطمئن شو هشدار خودکار با دکمه منو خاموش نشده باشد.

### هشدارها بعد از Deploy پاک شدند

مسیر دیتابیس روی میزبان موقت بوده است. از volume دائمی استفاده کن و `DATABASE_PATH` را به مسیری روی همان volume تغییر بده.
