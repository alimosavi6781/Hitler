# برنامه حرفه‌ای رشد سرشانه

برنامه تمرینی اصولی برای بزرگ‌کردن سرشانه (دلتوئید سه‌بخشی) — سطح متوسط، باشگاه کامل، بلوک ۸ هفته‌ای.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `shoulder-program.pdf` | **نسخه آماده اشتراک‌گذاری و چاپ** — ۷ صفحه A4، صفحه آخر کارت جلسه قابل چاپ |
| `index.html` | نسخه وب تعاملی: لاگر وزنه/تکرار برای هر ست (ذخیره خودکار در مرورگر)، نمودار آناتومی، نوار پیشرفت، دکمه چاپ |
| `quick-card.html` | کارت یک‌صفحه‌ای A4 برای بردن به باشگاه |
| `plan.md` | نسخه متنی کامل برنامه (خواندن در هر ادیتور یا کپی در یادداشت‌ها) |
| `build_pdf.py` | سازنده PDF از روی محتوای برنامه |
| `fonts/` | فونت وزیرمتن (woff2 برای وب، ttf برای PDF) — همه محلی، بدون CDN |

## مشاهده نسخه وب

```bash
python3 -m http.server 8000 --directory shoulder-program
# سپس در مرورگر: http://localhost:8000
```

## ساخت دوباره PDF

```bash
pip install fpdf2 arabic-reshaper python-bidi
python3 build_pdf.py     # خروجی: shoulder-program.pdf
```

نکته فنی: چون fpdf2 موتور شکل‌دهی متن راست‌به‌چپ ندارد، متن‌ها با `arabic-reshaper` (اتصال حروف) و `python-bidi` (ترتیب بصری) آماده و به‌صورت LTR راست‌چین رندر می‌شوند.

## ساختار برنامه در یک نگاه

- **Session A (روز اختصاصی):** ۷ حرکت، ۲۰ ست کاری + ۲ ست سلامت شانه — نشر جانبی محور اصلی، پشت شانه کامل، یک پرس سنگین.
- **دوز دوم (روز پرس/پشت):** ۵ تا ۶ ست — نشر جانبی کابل + نشر خم کابل.
- **حجم هفتگی:** حدود ۲۶ ست مستقیم دلتوئید، پخش‌شده روی ۲ جلسه با ۴۸ تا ۷۲ ساعت فاصله.
- **شدت:** RIR ۱ تا ۲ و در آخرین ست هر حرکت RIR ۰ تا ۱.
- **پیشروی:** دوگانه (تکرار ← وزنه)، با دیلود در هفته‌های ۴ و ۸.
- **شانه‌دوست:** گرم‌کردن اختصاصی، دامنه بدون درد، پرس لندماین به‌عنوان جایگزین، فینیشر روزتاتور کاف.

## هشدار

این برنامه راهنمای آموزشی عمومی برای فرد با سابقه تمرینی متوسط، دسترسی به باشگاه کامل و بدون آسیب حاد شانه است. در صورت وجود درد، سابقه دررفتگی، پارگی یا جراحی شانه، پیش از اجرا با پزشک ورزشی یا فیزیوتراپیست مشورت کنید.
